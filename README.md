# PUYOTRIS

**ぷよぷよ × テトリス** のミックスパズルゲーム。ブラウザだけで動作し、外部ライブラリ・ビルドツール不要の素のHTML/CSS/JavaScript(ESモジュール)で作られています。

- 🧩 テトリミノ(I/O/T/S/Z/J/L)が降ってくる、けれど各ブロックには**ぷよぷよの色**がランダムに1色ずつ付いている
- 🟥 **色消し**: 同色ブロックが上下左右に4つ以上つながると消える(ぷよぷよ方式)
- 🟦 **ライン消し**: 横一列が埋まると消える(テトリス方式)
- 🔗 消去 → 落下 → 再消去、で**連鎖**が発生。連鎖数・同時消しラインに応じて相手へ「おじゃまブロック」を送る対戦仕様
- ⌨️ **キー設定画面**で P1 / P2 のキーを自由に割り当て可能(競合検出つき)
- 🕹️ **2人対戦**モード(1台のキーボードで画面分割対戦)
- 🤖 **AI対戦**モード。相手は遺伝的アルゴリズムで訓練された評価関数ベースのAI
- 🧬 **AI訓練ラボ**画面。ブラウザ上でAIを世代交代させて自分で鍛えられる

## 遊び方

```bash
# リポジトリ直下で
node tools/serve.js
# → http://localhost:8080/ を開く
```

ESモジュール(`<script type="module">`)を使っているため、`index.html` を直接ダブルクリックで開くと動きません(ブラウザがfile://からのモジュール読み込みをブロックするため)。上記の簡易サーバーを使うか、`npx serve` などお好きな静的サーバーで配信してください。GitHub Pagesにそのまま置いても動きます。

### 操作(初期設定)

| 操作 | P1 | P2 |
|---|---|---|
| 左/右移動 | ←/→ | A/D |
| ソフトドロップ | ↓ | S |
| ハードドロップ | ↑ | W |
| 右回転 | X | E |
| 左回転 | Z | Q |
| ホールド | C | F |

メニューの「キー設定」からいつでも変更できます。

## AIについて(仕組みと設計判断)

「機械学習AI」という要望に対して、本プロジェクトは**遺伝的アルゴリズムで進化させた重み付き評価関数**を採用しています。理由:

- 本格的な深層強化学習(CNN + PPOなど)は学習にGPUと長時間を要し、ブラウザだけで実用的に訓練するのは非現実的です。
- 一方で遺伝的アルゴリズムは、「盤面特徴量(積み上げ高さ・穴の数・凹凸・消去数・連鎖数・同色隣接度など)にどれだけ重みを置くか」というベクトルを自己対戦で進化させる、正真正銘の機械学習手法です。軽量で、ブラウザ上でもリアルタイムに近い速度で世代交代を確認できます。

学習ロジック(`js/genetic.js`)はブラウザの「AI訓練ラボ」画面と、Node.js製のオフライン学習スクリプトの両方から**同じコード**として読み込まれます。

### ブラウザで訓練する

メニュー → 「AI訓練ラボ」→ 個体数・最大手数を設定 → 「1世代を実行」または「5世代を実行」。
気に入ったら「このAIを使う」を押すと、以後の「AI対戦」でそのAIが使われます(ブラウザのlocalStorageに保存)。「JSONを保存」でファイルとしてダウンロードもできます。

### Node.jsでオフライン訓練する(高速)

```bash
node tools/train-node.js [個体数] [世代数] [最大手数]
# 例:
node tools/train-node.js 30 40 300
```

実行後、最も強かった個体の重みが `ai-weights.json` に書き出されます。このファイルはWebアプリ起動時に自動で読み込まれ、デフォルトのAIの脳として使われます(レポジトリに同梱の `ai-weights.json` はサンプルとして小規模訓練済みのものです。より強くしたい場合は世代数・個体数・最大手数を増やして再訓練してください)。

## GitHubへの公開手順

このプロジェクトはあなたご自身のGitHubリポジトリにアップロードする想定で作られています。

```bash
cd puyotris
git init
git add .
git commit -m "Initial commit: PUYOTRIS"
git branch -M main
git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
git push -u origin main
```

**GitHub Pagesで公開する場合**: リポジトリの Settings → Pages → Source を `main` ブランチ / ルートに設定するだけで、`index.html` がそのまま公開されます(静的ファイルのみなのでビルド不要)。

## プロジェクト構成

```
puyotris/
├── index.html              # 画面構造(メニュー/キー設定/対戦/訓練ラボ)
├── css/style.css            # 見た目(アーケード筐体風ネオンデザイン)
├── ai-weights.json          # AIのデフォルト重み(train-node.jsで再生成可)
├── js/
│   ├── constants.js         # 盤面サイズ・色・ピース形状・キー初期値
│   ├── board.js             # 盤面ロジック(色消し・ライン消し・連鎖・おじゃま)
│   ├── piece.js              # 落下ピース(回転・移動・衝突判定)
│   ├── game.js               # 1人分のゲームセッション進行
│   ├── input.js              # キー設定の保存/読込 + 入力ポーリング(DAS/ARR)
│   ├── ai.js                  # 盤面評価ヒューリスティック + 最善手探索
│   ├── genetic.js            # 遺伝的アルゴリズム本体(ブラウザ/Node共通)
│   ├── render.js              # Canvas描画
│   └── main.js                 # 画面遷移・ゲームループ・訓練ラボUI
└── tools/
    ├── serve.js               # ローカル確認用の簡易静的サーバー
    └── train-node.js          # オフラインAI訓練CLI
```
